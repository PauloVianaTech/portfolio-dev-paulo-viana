# Paulo Viana — Portfolio

Portfólio pessoal desenvolvido para apresentação de projetos de desenvolvimento, automação, interfaces e soluções digitais.

## Tecnologias utilizadas

- React
- Vite
- Tailwind CSS
- Framer Motion
- Three.js
- GSAP
- Supabase

## Executar localmente

```bash
npm install
npm run dev
